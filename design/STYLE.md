# Style reference: "paper poster"

Source: GT FSA's "meet our eboard" Instagram carousel (11 slides: cover,
overview, 8 profiles, "see ya!" closer). This file records what was taken
from it and how the site maps onto it. Not part of the build.

## The source style

- **Palette:** warm off-white paper, plain black type, one brick red for
  everything hand-made. All other color comes from photos.
- **Three type voices:** (1) clean geometric grotesk, uppercase, medium,
  centered slide titles + small uppercase captions; (2) giant bold
  lowercase watermark in ghost grey, stacked tight and cropped by the frame;
  (3) red hand: a monoline script signature, uppercase marker labels.
- **Marks:** boxed numerals 1 2 3; red `[  bracketed  ]` captions with wide
  spacing; hand annotations: arrows, circled words, swooshes, tick-ended
  measurement bars.
- **Illustration:** each person has a red line mascot, posed once per fact.
- **Images:** cutout photos on blank paper; a black-bordered frame behind
  each holds a halftone zoom of the same subject; a dot-matrix pixel drawing
  on the closer.
- **Composition:** a sequence of slides with lots of white space, centered
  titles, and asymmetric poster balance; profiles alternate left/right.

## How the site maps onto it

| Slide | Site section | Source elements |
|---|---|---|
| cover | `#home` | ghost "hi, / i'm / sammy", mascot waving, bracket caption |
| profile | `#about` | centered title, 3 boxed facts + mascot poses, halftone frame, ghost name, signature |
| overview | `#experience` | grid of roles, each labeled by hand (circle / arrow / bar / swoosh) |
| profiles | `#projects` | boxed numbers, doodles, uppercase names, bracket link tags |
| "see ya!" | `#contact` | dot-matrix mascot, bracket caption, signature |

Fonts: Figtree (grotesk + ghost), Architects Daughter (marker labels),
Sacramento (signature). Mascot: a cat, Sammy's own character.
